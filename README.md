# 🧮 Calculator Web Application

A simple and interactive Calculator Web Application developed using HTML, CSS, and JavaScript. This project performs basic arithmetic operations through a clean and user-friendly interface.

## 🚀 Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Clear Display (C)
* Responsive User Interface
* Real-time Input Display
* Error Handling for Invalid Expressions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Calculator
│
├── index.html
├── style.css
└── script.js
```

## 🎯 How It Works

1. Click the number buttons to enter values.
2. Select an arithmetic operator.
3. Press the "=" button to calculate the result.
4. Press "C" to clear the display.

## 📸 Output

A calculator interface that allows users to perform basic mathematical calculations efficiently.
